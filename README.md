# مسطرة | الإصدارات

إصدارات برنامج مسطرة لتقطيع ألواح الورشة وأعواد الألوميتال، لنظام Windows. هنا ملفات البرنامج وملاحظات كل إصدار فقط.

## التشغيل لأول مرة

1. من [آخر إصدار](https://github.com/MohamedSalah-13/warsha-cut-releases/releases/latest) نزّل الملف `WarshaCut-<الإصدار>-windows-x64.zip`.
2. فك الضغط، وشغّل `WarshaCut\WarshaCut.exe`. لا يحتاج إلى تثبيت Java.

## التحديث

1. نزّل نسخة احتياطية من «نسخ احتياطي» واحتفظ بها.
2. أغلق البرنامج، ونزّل ملف الإصدار الجديد، واستبدل مجلد WarshaCut القديم بالجديد.
3. بيانات الورشة في `%LOCALAPPDATA%\WarshaCut\data`، خارج مجلد البرنامج، فلا يمسها الاستبدال.

اقرأ «قبل التحديث» في ملاحظات كل إصدار قبل تثبيته. الإصدارات بعد 0.5.6 تُظهر شريطًا أعلى صفحاتها حين يُنشر هنا إصدار أحدث.
